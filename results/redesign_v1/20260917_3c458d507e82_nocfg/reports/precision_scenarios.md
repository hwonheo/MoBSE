# δ=0.02 정밀도 시나리오 — WI-03 산출물 (2026-09-18)

지침서 WI-03 의 출력이고 계획서 §8 의 다음 요구를 따른다.

> 정밀도 계획은 QC 후 N과 사전 paired-error discordance/상관 시나리오로
> simulation하며, 분리된 pilot의 추정은 불확실성과 함께 보조적으로 사용한다.
> **metadata만으로 paired effect power를 추정했다고 하지 않는다.** 목표δ를 검출할
> 정밀도가 부족하면 **inconclusive 가능성을 명시한다.**

## 0. 결론부터

**현재 설계는 δ=0.02 를 검출할 정밀도가 없다.**

가정한 어느 시나리오에서도, 참 효과가 정확히 δ=0.02 일 때 97.5% CI 하한이 0을
넘을 확률은 **N=126 에서 0.04–0.19**, **N=189 에서 0.06–0.30** 이다. 계획서가
"실질적 우월성"으로 정의한 **하한 > δ 는 그 16개 칸에서 0.008–0.015** 로,
귀무(δ=0)에서의 오탐률 0.0125 와 사실상 구분되지 않는다.

이것은 실패가 아니라 사전에 알아야 할 사실이다. 계획서 §8 이 이미
"유의성은 실행 gate 가 아니다"라고 정했고, 그 문장의 실질적 의미가 여기서
확정된다 — **주 대조가 불확실(CI 가 0 포함)로 끝날 가능성이 가장 높은
결과다.** 그 경우를 실패로 숨기지 않고 그대로 보고한다.

## 1. 무엇을 simulation 했나

공식이 아니라 자료를 생성해 **계획서가 정한 bootstrap 절차를 그대로** 돌렸다.

### 1.1 생성 모형

subject i, task t 의 두 cell 사이 정오 차이를 `Δ_it ∈ {-1, 0, +1}` 로 둔다
(+1 = A만 맞음, −1 = B만 맞음, 0 = 둘 다 같음). McNemar 구조다.

```
P(Δ = +1) = (π + δ) / 2
P(Δ = −1) = (π − δ) / 2
P(Δ =  0) = 1 − π
```

* **π** = discordance rate. 두 cell 의 판정이 갈리는 subject 비율.
* **δ** = 그 task 의 참 효과. `|δ| ≤ π` 가 구조적 상한이다.
* 두 task 는 잠재 정규 copula 로 상관 **ρ** 를 준다.
* subject 의 endpoint 차이는 `d_i = (Δ_emo + Δ_wm)/2`, BA 차이는 `mean_i(d_i)` —
  계획서 §8 의 `b_i` 정의와 정확히 같다.

**주변 정확도는 들어가지 않는다.** paired 차이의 분포는 π 와 δ 만으로 정해진다.
"기준선이 몇 % 맞힌다" 같은 가정이 필요 없다는 뜻이고, 가정을 하나 덜 쓴다.

### 1.2 bootstrap

계획서 §8 그대로다 — **n_boot 10,000**, percentile **1.25–98.75** (97.5% CI,
family-wise 95% 를 보수적으로 제어), group = subject (개정 P4).

`d` 가 다섯 값만 취하므로 재표집 평균의 분포는 다섯 칸 multinomial 과 **정확히**
같다. 그 경로를 써서 n_boot 를 줄이지 않고 grid 전체를 돌렸다. 동치성은
`tests/v2/test_precision_simulation.py` 가 확인한다 —
(a) group=subject 에서 group bootstrap 이 subject bootstrap 과 **재표집 배열까지
완전히 동일**함, (b) multinomial 경로와 index 경로의 CI 차이가 격자 한 칸
(`0.5/N`) 규모를 넘지 않고 계통 편차가 없음.

### 1.3 검증

δ=0 인 칸에서 P(하한>0) 는 **0.006–0.017** 로 나왔다. 97.5% CI 의 이론값
`(1−0.975)/2 = 0.0125` 와 일치한다. **절차가 보정되어 있다는 뜻이고, 아래
숫자가 낮은 것은 절차 결함이 아니라 설계의 정밀도 문제다.**

### 읽는 법

**CI 반폭이 δ 보다 훨씬 크다.** N=126, π=0.10 에서 반폭 0.044 이고 δ 는 0.02 다.
효과가 목표치만큼 존재해도 CI 는 0 을 두 배 넘게 감싼다. 그것이 위 표의
0.11 이 나오는 이유이고, 표본을 189 로 늘려도 0.13 밖에 안 되는 이유다.

**ρ 가 올라가면 나빠진다.** 두 task 의 오차가 같이 움직이면 subject 당 평균이
분산을 덜 줄인다. ρ=0.5 는 ρ=0 대비 반폭을 8–15% 넓힌다.

**π 가 지배적이다.** discordance 가 0.05 에서 0.30 으로 가면 반폭이 2.4–2.8배가
된다. 두 cell 이 자주 갈릴수록 차이를 재기 어렵다. **그런데 π 는 우리가 모른다.**

## 3. pilot 은 π 를 좁히지 못한다

계획서는 "분리된 pilot 의 추정은 **불확실성과 함께** 보조적으로 사용한다"고
적었다. pilot 은 31명이다. π 의 Wilson 95% 구간:

| 참 π | pilot 31명 Wilson 95% | 폭 |
|---:|---|---:|
| 0.05 | [0.012, 0.187] | 0.175 |
| 0.10 | [0.035, 0.253] | 0.218 |
| 0.20 | [0.096, 0.370] | 0.274 |
| 0.30 | [0.168, 0.476] | 0.308 |

**pilot 이 π=0.10 을 보고해도 실제는 0.035–0.253 어디든 될 수 있다.** 위 표에서
그 구간은 P(하한>0) 를 0.05 에서 0.19 까지 가른다. 즉 **pilot 으로 정밀도를
확정할 수 없다.** pilot 은 구현 가능성·장비 비용·기준선 동작을 보는 용도로
쓰고(계획서 WI-03), 정밀도 주장의 근거로는 쓰지 않는다.

## 4. 그래서 이 설계가 검출할 수 있는 것

"80% power 를 확보했다"고 적지 않기 위해 반대로 물었다 — **80% 를 주려면 효과가
얼마여야 하는가.** 각 (N, π, ρ) 에서 `P(CI 하한 > 0) = 0.80` 이 되는 δ 를
이분법으로 찾았다(같은 생성 모형, 같은 bootstrap).

| π | ρ | N=126 δ₈₀ | N=189 δ₈₀ | N=126 배수 (÷0.02) |
|---:|---:|---:|---:|---:|
| 0.05 | 0.0 | **0.041** | 0.034 | 2.0× |
| 0.05 | 0.5 | **0.042** | 0.038 | 2.1× |
| 0.10 | 0.0 | **0.061** | 0.048 | 3.0× |
| 0.10 | 0.5 | **0.067** | 0.056 | 3.4× |
| 0.20 | 0.0 | **0.088** | 0.073 | 4.4× |
| 0.20 | 0.5 | **0.098** | 0.083 | 4.9× |
| 0.30 | 0.0 | **0.105** | 0.089 | 5.3× |
| 0.30 | 0.5 | **0.125** | 0.102 | 6.3× |

가장 유리한 가정(π=0.05, ρ=0)에서도 **δ 가 0.041 은 되어야** 80% 가 나온다.
계획서의 δ=0.02 의 **두 배**다. discordance 가 10% 면 세 배, 20% 면 네 배가
넘는다. 어느 칸에서도 `ceiling` 은 아니었다 — 즉 δ 를 충분히 키우면 도달은
하지만, 그 δ 가 사전 등록한 최소 효과보다 2–6배 크다.

**이 표는 느슨한 쪽 기준이다.** `하한 > 0`(추가 기여 지지)에 대한 값이고,
계획서가 "실질적 우월성"으로 정의한 `하한 > δ` 는 더 큰 효과를 요구한다.

표본을 126 → 189 로 키워도 δ₈₀ 은 15–20% 밖에 줄지 않는다. √N 스케일이므로
당연한 결과이고, **δ=0.02 에 닿으려면 N 이 수천 명 규모여야 한다**는 뜻이다.

### 4.1 재현성

grid 48칸을 서로 다른 시각에 두 번 돌렸고 **48칸 전부 값이 완전히 동일**했다
(seed 고정). 위 숫자는 우연이 아니다.

## 5. 명시하는 한계

1. **주 contrast 는 둘이다.** 계획서 §8 은 "두 primary 가 모두 지지되어야"
   결론을 쓴다고 정한다. 위 grid 는 **contrast 하나**를 모형화했다. 두 대조
   (A−B, A−C)는 A 를 공유하므로 양의 상관이 있고, 결합 확률은 단순 곱보다
   높지만 **이 문서는 그 결합을 simulation 하지 않았다.** 곱(예: 0.11² ≈ 0.01)은
   하한으로도 쓰지 않는다 — 상관 구조를 모르면서 숫자를 만들지 않는다.
2. **π 와 ρ 는 가정이다.** 실측값이 아니다. 네 개의 π 와 두 개의 ρ 를 놓고
   결과가 그 범위에서 어떻게 움직이는지를 보였을 뿐이다.
3. **내부 OOF 의 조건부성.** 계획서 §8 이 적었듯 내부 bootstrap 은 고정된 학습
   결과에 조건부이며 training-set 변동을 반영하지 않는다. 위 simulation 도
   그 변동을 담지 않았다. **실제 CI 는 여기 숫자보다 낙관적일 수 없다.**
4. **N=189 행은 외부 코호트 규모의 참고치**다. 외부 평가는 고정 모델을 새
   cohort 에 적용하는 것이라 내부 OOF 와 같은 양이 아니다 (§8).
5. **δ 를 바꾸지 않는다.** 계획서 §8 은 "main OOF 후 δ 나 분석 N 을 유리하게
   바꾸지 않는다"고 정했다. 이 문서는 main OOF **전**에 쓰였고, δ=0.02 는
   그대로 둔다. 정밀도가 부족하다는 사실이 δ 를 키울 근거가 되지 않는다.

## 5.1 그렇다면 무엇을 하나

계획서가 정한 답이 이미 있다.

> **유의성은 실행 gate 가 아니다.** 내부 결과가 음성이어도 데이터와 설계가
> 잠겨 있으면 외부 검증을 수행하고 같은 가설을 보고한다.

따라서 계획대로 실행하고, **결과를 "불확실"로 보고할 준비를 하고 시작한다.**
비유의를 효과 없음이나 동등성으로 바꾸지 않는다. 사전에 이 문서가 있으므로,
결과가 나온 뒤에 정밀도 부족을 사후 변명으로 꺼내는 일도 없다.

표본을 늘리는 선택지는 이 계획 밖이다. AOMIC PIOP1+PIOP2 를 합쳐도
126+189 이고, 계획서 §9 는 PIOP2 를 held-out 으로 못박았다. 지침서 WI-03 은
"단지 작은 N 이면 **임의 증원 대신 제한을 보고한다**"고 정한다. 이 문서가
그 보고다.
