# MoBSE 재설계안: 시간 정보의 조건 일반화와 시간표 혼입 구분

2026-10-17 · 제안서, 실행 승인·사전등록 잠금 아님

## 핵심 추천

**시간 정보를 쓰는 강한 선형 모델을 중심에 두고, 시간표가 달라져도 조건 구분 이득이 남는지를 주가설 하나로 검정한다.** MoE와 그래프는 필수 요소가 아니다. 현재 자료는 조건과 블록 위치가 완전히 겹치므로, 이 가설을 독립적으로 판별할 자료 설계가 먼저 필요하다. 기존 결과를 실패로 덮거나 P1의 확증 판정을 철회하지 않는다.

이번 작업은 저장된 설계·검토 기록을 읽고 이 문서만 작성했다. 새 적합·실험·기존 실제 입력 시계열 분석·표본 추가·전처리 재실행은 하지 않았다. 저장소 원본·Git·Notion은 수정하지 않았다.

## 1. 기존 자료에서 무엇을 식별할 수 있는가

| 근거 | 기록된 설계 | 가능한 판단과 불가능한 판단 |
|---|---|---|
| I3 잠금 §3·7 | PIOP1 157명 모두 8개 30초 블록, `c e c e c e c e`; onset+6초부터 15 frame; blockz | 같은 시간표를 새 사람에게 적용했을 때의 예측 성능은 평가 가능. 동일 위치의 c 대 e 대비는 불가능 |
| PIOP2 잠금 §2·5 | 메타데이터 점검 대상 222 run 모두 같은 순서, 적격 평가 189명 | cohort가 달라도 시간표가 같아 조건 대 시간표를 분리하는 교차 조건이 생기지 않음 |
| 현재 사용 이력 | PIOP1 개발·평가, PIOP2 확증 및 사후 진단에 이미 사용 | 둘 다 새 설계의 독립 확증 표본으로 재지정할 수 없음 |

**식별 불가능의 이유:** 현재 자료에서는 조건 label이 블록 홀짝의 결정적 함수다. 위치를 고정하면 label 변이가 없고, 조건과 위치를 회귀식에 동시에 넣어도 독립 효과를 추정할 정보가 생기지 않는다. 잔차화, 위치 매칭, 사람 단위 교차검증, 첫 블록 쌍 제외, 정규화, 순열검정으로 이 빈 교차 조건을 만들 수 없다.

사람 단위 split은 같은 사람의 정보 누출을 막지만, 모든 사람에게 반복되는 시간표 단서는 train과 test에 그대로 남는다. 두 cohort 사이 평가도 같은 문제를 갖는다. 기존 I3 문서의 “같은 입력이므로 칸 간 차이에는 같은 방식으로 작용”이라는 표현은 엄격한 보장이 아니다. 같은 입력에서도 모델마다 시간표 단서를 활용하는 정도가 다를 수 있다.

이 판단은 위 잠금 문서의 기존 metadata 점검 결과에 근거한다. 이번에 원 events나 입력 시계열을 다시 읽어 확인한 것은 아니다. 기록되지 않은 순서 변이가 있다고 가정하지 않는다.

## 2. 보존할 결과와 출발점

- **P1 확증 유지:** PIOP2에서 B embedding−FC logistic = +0.1283, 97.5% CI [0.0952, 0.1607]. 이는 등록된 기준선 대비 성능 주장이다. 시간표와 독립적인 조건 정보 또는 그래프 고유 효과를 확증한 것은 아니다.
- **full-TS 사후 진단:** 블록 시계열을 펼친 선형 logistic 정확도는 PIOP1 0.840 대 B 0.712, PIOP2 0.848 대 B 0.828. PIOP2 B−fullTS의 95% CI는 0을 포함한다. 동등성 검정은 아니며, 두 자료의 진단 모두 새 확증으로 승격하지 않는다. 시간 배열을 보존한 특징이 FC보다 유리할 수 있다는 근거지만, 그것이 조건 반응인지 시간표 관련 신호인지는 미분리다.
- **실제 복원 pilot:** 31명, BEST-T−F4R1 NMSE = −0.001158, 95% CI [−0.001868, −0.000536], τ=0 5/5, fallback 0. 이는 현재 rest→task 상태 적응 복원의 이득을 지지하지 않는다. 분류와 복원은 과제·지표가 달라 수치를 합치지 않는다. 뇌 상태의 부재를 뜻하지 않는다.
- pilot 자동 flag는 원래 BEST7 대비, 실제 주지표는 BEST-T 대비여서 판정 문구가 다르다. 원본 보존 상태의 정정 설명을 유지한다. `synthetic_only=True` 표기 오류도 기존 결과 보고서의 설명을 함께 보존한다.

## 3. 주가설 하나와 핵심 비교

**주가설 H:** 조건과 시간표가 교차하도록 설계된 독립 자료에서, 시간 배열을 보존한 full-TS 선형 모델은 FC 선형 모델보다 미사용 사람·미사용 시간표에서 조건 구분 성능이 높다.

**단일 주 contrast:** 사람별 balanced accuracy 차이 Δ = BA(full-TS linear) − BA(FC linear). 목표는 “시간 배열을 보존한 표현의 추가 예측 가치”이며, 신경학적 인과 효과나 동적 covariance 상태를 직접 증명하는 가설이 아니다. 두 모델 간 특징 차이는 시간 순서 외에도 공분산 요약에서 사라지는 파형 정보를 포함한다.

**주 평가 환경:** 조건이 각 시간 위치에서 모두 관측되고 전이 이력도 균형을 이루는 독립 test 설계. train과 test는 사람을 완전히 분리하고, test 시간표는 개발·선택에 쓰지 않은 순서 집합으로 둔다. test 집합 내부에서도 조건×위치 균형을 확보한다. 단순히 기존 CE를 train, EC만을 test로 두는 것은 유용한 전이 진단일 수 있지만 그 하나만으로 모든 시간표 혼입이 제거되었다고 판단하지 않는다.

**판정 제안, 아직 잠금 아님:** 주 contrast 하나에 사람 단위 95% CI를 적용하고 하한이 사전 지정 최소 효과 δ를 넘을 때 지지한다. δ=BA 0.02는 논의용 출발값이며 기존 결과에서 정당화된 값이 아니다. 목적·비용과 새 설계의 검정력을 확인하여 성능 개봉 전에 확정한다. 하한이 0보다 높지만 δ 이하이면 실질적 이득은 미확정, CI가 넓으면 불확실, 상한이 δ보다 낮으면 목표 크기의 이득을 지지하지 않는 것으로 구분한다. 사람 수보다 블록 수를 독립 표본 수처럼 사용하지 않는다.

## 4. 비교 조건과 각 조건의 역할

| 조건 | 입력·역할 | 해석 주의 |
|---|---|---|
| Timing-only | BOLD 없이 블록 위치·절대/상대 시간·run 위치 등 추론 시 실제 이용 가능한 시간 정보만. 조건명·정답을 직접 인코딩한 schedule key는 제외 | 기존 자료에서는 parity 규칙만으로 label이 결정된다는 설계상 결함을 드러냄. 이는 이번에 측정한 정확도 수치가 아님. 독립 설계에서는 지정된 시간 특징이 여전히 조건을 예측하는지 점검 |
| FC linear | 동일 ROI·동일 전처리·동일 블록 frame에서 얻은 FC + 선형 분류 | full-TS와 원자료 접근 범위는 같지만 표현의 정보는 같지 않음. 이 차이가 주 비교의 대상 |
| Full-TS linear | 같은 블록 시계열을 펼친 정규화 선형 분류 | 권장 중심 모델. 위상·파형·위치 단서를 모두 이용할 수 있어 counterbalance가 필수 |
| Embedding | 동일 블록 시계열, routing을 고정한 모델 | 보조 비교. full-TS를 넘어서는 고유 이득이 있는지 평가. 주가설 판정에는 쓰지 않음 |

세 BOLD 모델은 같은 사람 split·ROI·블록·전처리·결측/QC 규칙·label 접근 범위와 같은 inner 선택 자료 및 목적함수를 사용한다. 전처리 변형을 모델마다 유리하게 고르지 않는다. 정규화 후보·seed·early stopping·계산 예산을 개봉 전 기록하고, 모델별 타당한 범위를 갖되 특정 모델에만 반복적인 사후 선택 기회를 주지 않는다. 후보 개수가 같다는 것만으로 튜닝 공정성이 보장되지는 않는다. timing-only는 설계 감사용으로 별도 해석하며, BOLD 모델에 timing 정보를 추가하는 비교를 주 분석에 자의적으로 끼워 넣지 않는다.

## 5. 음성 대조와 누출 방지 — 무엇을 해결하고 못 하는가

- **Label 음성 대조:** 새 무작위/균형 설계의 할당 단위와 교환가능성에 맞춘 randomization 대조를 사전 지정한다. 반복 블록을 독립처럼 뒤섞지 않는다. 기존 고정 CE 자료의 단순 label 순열은 그 시간표 단서까지 깨므로, 원래 성능이 높다는 것만으로 조건 신호를 입증하지 못한다.
- **시간 순서 훼손/shift:** 모델이 파형 배열에 의존하는지 보는 보조 진단일 뿐이다. shuffle은 자기상관과 진짜 조건 반응을, shift는 label 정렬·경계·교란을 동시에 바꿀 수 있다. 성능 하락은 “시간표 혼입이 제거됐고 진짜 신호만 남았다” 또는 그 반대의 증거가 아니다. 원래 분포에서 벗어나는 효과도 포함한다.
- **누출 방지:** 한 사람의 모든 run·block은 같은 split에 둔다. scaler·특징선택·PCA·정규화·모델선택은 train/inner 자료만 사용한다. 같은 블록 또는 겹치는 frame이 train/test에 나뉘지 않게 한다. test 결과를 보고 후보·전처리·배제 기준을 바꾸지 않는다. 이는 구현 누출을 막으며 시간표와 조건의 구조적 혼입을 해결하지는 않는다.
- **전처리 주장 범위:** 현행 full-run 처리와 blockz를 쓴다면 offline 블록 분류로 한정한다. 다른 frame의 정보를 쓰는 필터링·회귀를 인과적 온라인 처리로 부르지 않는다. 전처리를 바꾸는 연구는 별도 설계로 둔다.

## 6. 기존 자료의 탐색과 독립 확증을 분리

**기존 자료로 가능한 것:** 저장된 예측·사람별 점수·선택 기록의 기술 집계, 시간표 혼입 구조의 문서화, 기존 P1/fullTS 결과와 강한 기준선의 비교 정리. 향후 별도 승인하에 기존 자료를 다시 적합하더라도 결과는 탐색이며 조건/위치의 독립 효과를 식별하지 못한다. 새로운 split을 만드는 것으로 사용 이력이 초기화되지 않는다. 이번 문서에서는 추가 집계·실험을 실행하지 않았다.

**독립 확증에 필요한 조건:** 새로 확보하거나 별도 승인 후 적합성을 검토할 미사용 자료에 다음이 있어야 한다.

1. 조건×블록 위치가 교차하고 각 위치에 두 조건이 충분히 존재해야 한다. 반대 시작 순서만으로 parity 혼입은 완화할 수 있으나, 계속 교대하면 직전 조건과 현재 조건의 관계는 여전히 고정된다. 반복 조건을 포함하는 여러 순서·전이 균형 등으로 carryover도 다룰 수 있어야 한다.
2. 순서 배정이 사람 특성·site·run과 완전히 겹치지 않아야 한다. 가능한 무작위 배정과 여러 순서 집합을 사용하고, HRF carryover·경계/휴식·자극 구성을 설계에 포함한다. 자극 차이까지 완전히 통제하지 않았다면 “추상적 감정 상태”가 아닌 “이 과제의 조건” 일반화로 주장한다.
3. 미사용 사람과 미사용 시간표에서 평가할 충분한 교차 셀과 표본 수가 있어야 한다. 설계 균형·QC·검정력 기준, 모델·δ·주 contrast를 test 성능 개봉 전에 고정한다. 이 단계에서 적합하지 않으면 확증을 시작하지 않는다.

이미 사용한 PIOP2는 이 새 독립 자료가 아니다. 기존 metadata 기록만으로 위 조건을 만족하는 대체 자료가 있다고 확인할 수 없으므로 특정 데이터셋의 적합성을 단정하지 않는다.

## 7. MoE와 추가 복잡성의 채택 기준

기본은 full-TS 선형 모델이다. embedding·그래프·MoE는 동일 정보와 공정한 선택 예산에서 강한 선형 모델보다 독립적으로 재현되는 추가 이득이 있을 때만 채택한다. MoE를 되살린다면 고정 혼합 대 적응 혼합의 고유 contrast도 필요하다. gate가 변한다거나 τ>0이 선택됐다는 것만으로 유용성을 주장하지 않는다. 계산비용·실패율·사람별 이질성을 같이 평가한다. 넓은 CI는 동등성이나 무용성의 증명이 아니며, 충분한 정밀도에서도 목표 이득이 없으면 단순 모델을 유지한다.

## 8. 결정이 필요한 최소 항목

1. **자료 경로:** 기존 자료는 탐색 기록으로 보존하고, counterbalance가 가능한 미사용 자료의 적합성 검토를 다음 단계로 할지, 새 수집 설계를 검토할지. 어느 쪽도 이번 문서 작성 승인에 실행 권한을 포함하지 않는다.
2. **실질적 효과의 목표:** 조건 일반화가 연구 목적임을 확인하고 BA δ의 기준을 정한다. 제안값 0.02는 새 자료·검정력 검토 후 잠금 전에 확정한다. 현 단계에서 MoE 구조나 하이퍼파라미터를 정할 필요는 없다.
