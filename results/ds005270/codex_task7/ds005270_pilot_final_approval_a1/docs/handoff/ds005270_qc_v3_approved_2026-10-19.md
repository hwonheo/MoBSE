# ds005270 QC v3 승인 반영

ds005270 QC v3 — 승인 반영 및 4명 검증 요약
2026-10-19 KST

승인 반영
• Schaefer-100 전체 입력 유지. ROI 삭제·보간 없음.
• sub-003: 실제 후방 FOV 부족으로 주 분석 제외 확정.
• sub-006: 기존 움직임·유효 창 기준에 따른 제외 유지.
• fMRIPrep 25.2.6 제공 white_matter/csf 평균을 새 nuisance 정의로 명시 채택. 기존 AFNI 침식 마스크와 동등하다는 주장은 하지 않음.

처리 정의
266개 frame, TR 2초, 시간 원점 0초·dummy 0. ROI는 Schaefer100과 기능 brain mask 교집합 voxel의 비가중 평균. ROI 및 제공 WM/CSF 평균을 각 run 평균으로 PSC 변환. 절편·선형 추세·motion6·후방 차분6(첫행0)·제곱12·WM/CSF2의 28열 OLS를 전체 run에 적용. 회전 입력은 radians, nuisance에서 degree로 변환; FD는 50mm 반경. 추가 필터·CompCor·global signal·회귀 내 censor·창별 z-score 없음. 비유한/0분산 또는 PSC 평균0은 실패 처리하며 보간하지 않음.
FD>0.5mm와 전후1 frame이 걸친 15-frame 창은 통째 제외. 주 창 조건별 최소3개 유지. 민감도 창으로 주 창 실패를 구제하지 않음.

검증 통과
sub-001/002/004/013의 기존 후보 결과를 해시 확인 후 재사용. 중복 BOLD 추출 없음.
• 시간축·266행·FD·주/민감도 창은 기존 결과와 일치. 각자 주 창4/4/4.
• 설계행렬266×28, rank28. 재구성한 설계행렬 정확히 일치, 잔차 재현 차이0.
• 100 ROI의 원시 및 잔차 유한·분산>0.
• 유효 주 창48개: fullTS1500 / FC4950 / 평균100 / 평균+SD200 입력 계약 확인.
• 어댑터 시험4개 및 기존 정책 시험5개 통과. 새 승인 제외와 검토 분리 검사 통과.

해석과 남은 일
낮은 ROI 마스크 포함률은 자동 제외가 아니라 개별 검토다. 유한값·분산·tSNR 기술 검증이 과학적 품질 통과를 뜻하지 않는다. 나머지4명의 국소 마스크/정합 및 잔여 ROI 대표성 검토가 남는다. 제공 regional mean의 실제 binary mask는 회수된 산출물에 없어, 재현은 고정 fMRIPrep 이미지와 실행기록·원본 confounds TSV 해시에 근거한다. 확률지도에서 임의 역치로 마스크를 재구성하지 않았다.
이번 묶음 과학적 결정은 반영 완료. 추가 수치 기준은 만들지 않았다. 기술 연결은 검증됐지만 전체 실행 준비 판정은 보류다.

미실행
