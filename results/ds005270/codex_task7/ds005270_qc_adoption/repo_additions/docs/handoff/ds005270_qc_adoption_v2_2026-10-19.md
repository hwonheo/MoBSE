# ds005270: fMRIPrep 기본 전처리 및 원인별 QC 반영
2026-10-19 KST. 사용자 “그럼 결론대로 진행”에 따른 설정·문서 개정. 기존 v1 잠금·원본·산출물은 보존한다. 이 문서와 protocol_v2_qc_policy.json은 후속 기본 정책이며, 전처리·추출·전체 코호트·학습 실행은 비활성이다. 기존 AFNI 구동기는 변경하지 않았으며 새 정책 실행기로 사용하면 안 된다.
## 확정 및 유지
- 기본 영상 전처리: 완료된 pilot과 동일한 fMRIPrep 25.2.6 고정 digest, MNI152NLin2009cAsym res-2, SyN fieldmap-less SDC, slice-time-ref 0, dummy 0, recon-all 없음. 세부 자원·참조 구동기는 JSON에 기록했다. fMRIPrep의 preproc BOLD는 nuisance 제거 ROI 시계열이 아니다. 기존 PSC·28열 nuisance 의도는 유지하되 radians motion·WM/CSF 마스크 대응 어댑터는 후속 검증 전까지 미완료 gate로 둔다.
- Q2 평균 FD >0.3 mm 또는 FD>0.5 mm 비율 >20%, Q3 조건마다 주 창 최소3개는 유지한다. 주 창 순서는 0/1/2-back이다. 민감도 창으로 주분석 실패를 구제하지 않는다.
- 마스크 포함률 <90%는 자동 사람 제외에서 검토 표시로 변경한다. 촬영범위, 신호, 마스크, 정합을 구분한다. 새 수치 역치는 만들지 않았다. 저포함만으로 저신호·정합 실패·신호 회복을 단정하지 않는다.
- 기존 100 ROI 전체의 공통 입력을 유지: fullTS 15×100=1500, FC 4950, 평균100, 평균+SD200. 모델별 ROI/사람/창 차이, 임의 ROI 제거·보간은 금지한다. 비유한/0분산 ROI는 기존대로 QC 실패다.

## 필요한 최소 과학적 결정과 권고
기존 ds005270 계획은 100개 ROI 전체를 모델 입력으로 정했지만, 더 좁은 과학적 필수 ROI 집합과 부분 촬영 허용 규칙은 없다. 별도 R2T 계획의 관측/가림 ROI 설계를 이 n-back 분류에 옮겨 적용하지 않는다.
**최소 질문:** 기존 Schaefer-100 전체 입력을 유지하고, 촬영범위가 부족한 sub-003은 계속 보류한 채 필요한 ROI·부분 촬영 수용 원칙을 먼저 확정할까요? 권고는 전체 100개 입력 유지와 sub-003 보류이며, pilot 결측을 보고 일부 ROI를 사후 제거하지 않는 것이다. 좁은 ROI 집합을 원하면 연구 목적에 근거한 ROI ID 목록과 모든 사람·모델에 공통 적용할 개정 계획이 별도로 필요하다. 새로운 부분 촬영 수치 기준은 여기서 확정하지 않았다.
나머지 4명은 움직임·창 기준을 통과했지만 최종 포함 승인이 아니다. 양측 안와전두·측두극 및 우측 Default temporal 잔여 영역, sub-004의 좌측 시각 ROI4를 개별 검토한다. 상관·Dice는 기술값이며 새 통과 cutoff로 쓰지 않는다. 전체 코호트나 학습 착수는 이번 승인에 포함하지 않는다.
