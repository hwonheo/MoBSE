## 1. 한 문단 요약

v1 의 target (AOMIC PIOP1 emomatching 대 workingmemory run identity) 은 단순 FC 분류기가 이미 다 맞혀
(S 1.000) "정렬된 뇌 배선도의 가치" (H2, A−C) 를 검정할 자리가 없었다. v3 는 target 을 그대로 두고
**학습 subject 수를 10–100 으로 줄여** 그 자리를 만들려 했다 (결정 30, T4). 결과는 그 전제가 서지 않았다는 것이다 —
**FC logistic (S3) 은 학습 10 명에서도 0.984** 였다. 그 위에서 A−C 는 수준마다 부호가 오르내려 일관된 곡선이 없고
(10 점 중 하한 > 0 두 점 · 상한 < 0 세 점), 한 지점의 null 분포 (G-c) 에서도 정렬된 bank 의 A 가 null bank 의
C 를 이기지 못했다. 설계상 δ=0.02 는 어느 점에서도 탐지할 수 없었다 (G-b, 탐지 확률 0.03–0.19).
라우팅의 이득 (A−B) 은 embedding 구조에서 다섯 점 중 네 점이 양수로 v1 과 같은 방향이지만, 모델 전체가
단순 기준선보다 17–35 %p 낮다. **이 자료와 이 target 에서는 정렬된 graph bank 의 가치를 보일 수 없었다.**
§6 의 학습 변동 측정이 그 판독을 확인했다 — **같은 점을 다시 학습하면 A−C 의 부호가 뒤집히고, 반복 평균은
네 점 모두 0 근처 (−0.015 ~ +0.014) 다.** 곡선에서 0 을 벗어났던 점들은 재학습 변동의 끝값이었다.

## 6. 학습 변동 (결정 35)

T4 곡선에서 점마다 97.5% CI 가 0 을 벗어난 점 넷을 골라 (구조 · 방향을 고루) 다시 학습했다. **결과를 보고 고른 점**이다 —
묻는 것은 "0 을 벗어난 점이 다시 학습해도 그대로인가" 다.

- 변동원 둘, 각 4 반복. **seed**: model seed 세 쌍을 (45–47) · (48–50) · (51–53) · (54–56) 으로. **부분표집**:
  `curve.subsample_seed_base` 를 40100 · 40200 · 40300 · 40400 으로 (학습 subject 가 실제로 바뀐다 — 예: embedding
  N=10 fold 0 에서 원판과 겹치는 사람 10 명 중 1 명). readout N=100 은 pool 이 100–101 명이라 부분표집 반복을 하지 않았다.
- inner 선택 (config · 공통 E) 은 본 실행 것을 고정했다. `mobse/v3` · v3 잠금은 그대로 두고 구동기가 프로세스 안에서만
  잠긴 seed 두 값을 덮었다 (결정 26 과 같은 방식). 1,680 fit, 실패 0, 00:59Z → 02:33Z.

**읽는 법**
1. **A−C 의 반복 평균은 네 점 모두 0 근처**다. 곡선에서 보인 ±0.05–0.09 는 각 점 범위의 **끝값**이었다 —
   0 을 벗어난 점을 골랐으니 끝값이 나오는 것이 자연스럽다 (선택 효과).
2. **재학습 변동 (SD 0.031–0.046) 이 bootstrap 반폭 (0.034–0.046) 과 같은 크기**다. 점마다 CI 는 test subject 표집만
   담으므로, 재학습 한 판의 CI 는 이 변동을 빠뜨린다. 실제로 반복 28 판 중 7 판 (25 %) 이 0 을 벗어났고, **같은 점에서
   양쪽 방향이 다 나왔다** (예: embedding N=10 원판 +0.087 [+0.044, +0.131], seed2 판 −0.056 [−0.103, −0.012]).
3. 같은 이유로 **A 자체도 재학습마다 크게 움직인다** — readout N=20 의 A 는 0.627–0.798.
4. A−B 는 embedding N=70 에서 아홉 판 모두 양수 (+0.139 ~ +0.210) 로 안정적이다. 다른 점에서는 0 아래로 내려간 판이
   있다. A−B 도 §8 한계 7 (FC 정보 경로) 의 범위 안에서 읽는다.
5. 함의: **이 설계에서 "한 번 학습한 모델의 bootstrap CI" 로 구조 기여를 판정하면, 효과가 없어도 네 판 중 한 판꼴로
   "유의" 가 나온다.** 다음 설계에는 재학습 변동을 CI 에 넣는 장치가 필요하다.

## 8. 음성 결과 · 구현 선택 · 한계 (숨기지 않는다)

**음성 결과**
1. T4 의 전제가 깨졌다 (C2). 저표본으로 포화를 우회하려던 설계가 이 target 에서는 우회하지 못했다.
2. H2 (A−C) 에 일관된 방향이 없다 (C3). 정렬된 bank 가 null bank 보다 낫다는 근거는 나오지 않았다 (C3 · C4).
3. ROI 정체를 쓰게 만든 두 구조 모두 A 를 v1 보다 끌어올리지 못했다 (§4).
4. readout 구조에서는 라우팅의 이득도 거의 사라졌다 (C5).

**구현 선택 (결정 아님, 표시)**
- S 는 logistic (S1 · S3) 만 — MLP S 는 v1 학습 규칙이 저표본에서 성립하지 않는다 (설계안 §5.3.1). **v1 의 S 선택은 대부분 S4 (MLP)** 였으므로 v3 의 A−S 는 v1 의 A−S 와 같은 비교가 아니다.
- null seed = 1729 + 100 × index. 주 null 이 아닌 fit 은 `select` · `evaluate` 가 거부한다.
- G-c 지점 = fold 0 · N=100 · seed 42 · 구조 둘 · C·D. 실행 순서 inner → G-c → outer.
- 실험 구동기는 `scripts/exploratory_v2/` — v1 gate evidence 의 등록 대상이 아니다 (결정 28).

**한계**
1. bootstrap CI 는 test subject 표집 변동만 담는다 — §6 에서 잰 재학습 변동이 그와 같은 크기라, 점마다 CI 는 과신이다.
2. δ=0.02 는 endpoint 양자 (1/252 ≈ 0.004) 의 약 5 배다 (v1 G1 fail [6] 승계).
3. G-c 는 한 fold · 한 seed 다.
4. 곡선 10 점의 다중성은 동시 99.75% 를 참고로만 적었다 (결정 34).
5. inner 선택 (config · 공통 E) 은 가장 큰 수준에서 한 번 고른 것을 모든 수준이 쓴다 — 저표본 점에 최적인 config 가 아닐 수 있다.
6. 외부 검증 (PIOP2) 은 하지 않았다 (결정 27).
7. **A−B (H1) 는 "라우팅 메커니즘" 의 효과가 아니라 "그 창의 FC 정보 경로" 의 효과로 읽어야 한다.** A 의 gate 는
   창 자신의 FC (PCA 10) 를 받고 B 는 FC 가 예측에 들어갈 길이 없다 — 계획서 §6 이 이미 "순수 parameter-only
   효과는 아니다" 라고 적었다. v1 에서 같은 FC PCA 를 그래프 · 라우팅 없이 이어 붙인 NG 가 A 와 구분되지 않았다
