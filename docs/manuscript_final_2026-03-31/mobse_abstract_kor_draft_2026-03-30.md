# MoBSE 국문 초록 초안 (2026-03-30)

## 1) 최종 초록 (현재 확정본)

실제 인간 resting-state fMRI 데이터는 개인차와 촬영 환경 차이가 커서, 모델 성능이 높아도 결과를 해석하기 어렵다. 최근 연구들은 작은 표본의 과대평가 위험과 전처리·하모나이제이션의 큰 영향을 보고했으며, 정확도만으로는 임상적 의미를 충분히 설명하기 어렵다는 점을 보여주고 있다. 본 연구에서 우리는 이러한 문제를 줄이기 위해 Mixture of Brain-State Experts (MoBSE)를 제안한다.

MoBSE는 Yeo-7 네트워크를 공통 해석 좌표로 사용하고, 복잡한 뇌 신호를 네트워크 단위로 분해해 학습한다. 이를 검증하기 위해 ABIDE PCP 성인 대조군 143명(min-age=18, CC200 ROI)으로 7개 상태 템플릿을 구성해 모델을 학습했으며, 시뮬레이션 대조군 150명에도 동일한 설정(노드 200, 전문가 7, 상태 7, 동일 FLOPs/지연시간)을 적용해 공정 비교를 수행했다. 평가는 분류 성능과 전문가 라우팅 특성, 그리고 추론 효율을 함께 보고했다.

그 결과, 시간창 단위 뇌 상태 분류 과제에서 ABIDE가 시뮬레이션보다 높은 성능을 보였다(loss 0.0033 vs 1.9671, accuracy 1.0000 vs 0.1324, F1-macro 1.0000 vs 0.1072). 반면 추론 1회당 연산량과 처리시간은 거의 같았다(FLOPs 86.38M 동일, 지연시간 약 2.49ms). 또한 전문가 선택의 분산 정도를 나타내는 라우팅 엔트로피는 ABIDE에서 더 낮았고(0.6098 vs 0.6692), 모델이 더 집중된 전문가 선택을 보였다.

본 연구에서 우리는 MoBSE가 성능 비교를 넘어, 예측 결과를 노드·네트워크 수준의 신경과학적 해석과 연결할 수 있는 실용적 분석 틀을 제공함을 보였다. 이는 향후 대규모 다기관 코호트 확장과 임상 전이 연구를 위한 기반 결과로 활용될 수 있다.

## 2) 용어 표기 정책 (최종 반영)

- 약어는 첫 등장 시에만 full name 병기:
  - `Mixture of Brain-State Experts (MoBSE)`
  - `resting-state functional magnetic resonance imaging (resting-state fMRI)`는 본문 통일성 때문에 현재는 `resting-state fMRI`로 유지
- 이후 반복 구간에서는 약어/통용 표기만 사용.
- 초록 내 설명형 문장 유지:
  - OS 과제: 시간창 단위 뇌 상태 분류 과제
  - 계산 효율: 추론 1회당 연산량(FLOPs)과 처리시간(latency)
  - 라우팅 엔트로피: 전문가 선택 분산 정도

## 3) 수정 과정 상세 로그

### V0 -> V1 (초기 구조 정렬)

- 적용 사항:
  - 기-승-전-결 구조를 초록 문단 구조로 변환.
  - 문제 정의(재현성/전처리 민감성) -> 제안 -> 결과 -> 의의 순서 확정.
- 수정 이유:
  - 논리 흐름은 명확하지만 문장 스타일이 설명문에 가까워 저널 초록 톤 보강이 필요했음.

### V1 -> V2 (근거 문헌 최신화 반영)

- 적용 사항:
  - 최근(2021-2025) 중심 문헌 프레임을 반영하여 배경 문장을 업데이트.
  - 과도한 고전 인용 의존을 줄이고, 재현성/하모나이제이션 중심 문제의식으로 재구성.
- 수정 이유:
  - 최신성 강화 및 독자(리뷰어) 설득력 향상.

### V2 -> V3 (가독성 개선)

- 적용 사항:
  - 전문 용어를 쉬운 설명으로 완화.
  - 문장 난이도를 낮춰 비전공자도 핵심을 따라오도록 조정.
- 수정 이유:
  - 사용자 요청: 전달력 우선, 이해도 확대.

### V3 -> V4 (논문체 어휘 정합)

- 적용 사항:
  - 구어체 표현 제거: `쉽게 말해` 제거, `즉,`로 통일.
  - 메타 표현 교체: `핵심 의의는` -> `본 연구에서 우리는`.
  - 제안 문장 순서 수정: 설계 설명 전에 `MoBSE 제안` 문장을 우선 배치.
- 수정 이유:
  - 저널 초록 문체와 주장 구조를 정합화.

### V4 -> V5 (Methods 정보 밀도 강화)

- 적용 사항:
  - 실험 방법 디테일 추가:
    - ABIDE PCP 성인 대조군 143명, min-age=18, CC200 ROI
    - 7개 상태 템플릿 구성
    - 시뮬레이션 150명 공정 비교
    - 동일 설정: nodes=200, experts=7, states=7, 동일 FLOPs/latency
  - 평가 축 명시: 성능 + 라우팅 + 효율.
- 수정 이유:
  - 기존 문장이 방법론 치밀도를 충분히 전달하지 못함.

### V5 -> V6 (결과 용어 설명형 전환)

- 적용 사항:
  - `OS`를 `시간창 단위 뇌 상태 분류 과제`로 풀어씀.
  - `계산 비용`을 `추론 1회당 연산량(FLOPs)과 처리시간`으로 풀어씀.
  - `라우팅 엔트로피`를 `전문가 선택의 분산 정도`로 풀어씀.
- 수정 이유:
  - 독자가 용어를 몰라도 결과 의미를 즉시 이해하도록 개선.

### V6 -> V7 (Abstract 경량화, Discussion 분리)

- 적용 사항:
  - 한계(window-level split, 상태 생성 비대칭, 전처리 민감도)는 초록 말미에서 제거.
  - 대신 전체 기여와 활용 가능성(다기관 확장/임상 전이 기반)으로 마무리.
- 수정 이유:
  - 사용자 요청: 초록은 overview 중심, 상세 한계는 Discussion에서 전개.
