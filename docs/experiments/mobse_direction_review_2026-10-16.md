## 2. 종합 — 무엇이 서고 무엇이 서지 않나

**서지 않는 것**
1. **MoBSE 의 두 원래 주장** — 입력 의존 routing 의 이득 (H1) 과 정렬된 뇌 graph bank 의 이득 (H2) — 은 어디에서도 지지되지 않았다. v1 의 양의 H1 은 gate 가 과제 label 을 따라 graph 하나를 고른 결과로 설명된다 (I3 마감본 C11, 사후 설명).
2. **MoBSE 가 단순 기준선보다 낫다** 는 주장. A−S 는 v1 −0.123 · v3 −0.17 ~ −0.35 · I3 −0.07 ~ −0.09, ABIDE 에서도 MoBSE 0.61–0.62 대 FC logistic 0.762. ADHD-200 에서만 비슷 (0.59–0.62 대 0.608).

**서는 것 (방법 쪽)**
3. **I1 검증 프로토콜의 결론** (C1–C5): null 판정은 null 종류와 무관하고 크기만 다름 (C2 지지 안 됨), 단일 학습 CI 는 작은 효과에서 '유의' 를 자주 냄 (C3), 포화 target 은 구조 비교의 정보를 잃음 (C4), 공개 저장소 재현에는 마찰이 큼 (C5). 세 자료에서 판정이 같았다.
4. **gate 진단**: 입력 의존 gate 가 입력 스케일 때문에 이산 선택기로 작동한다는 것, 그리고 그것이 v1 의 결과를 어떻게 만들었는지 (I3 C8–C11). 재현이 바이트 단위로 확인됐다.
5. **음성 결과 자체**: 포화 target 에서의 양성은 착시일 수 있고, 포화를 풀면 사라진다 (v1 → v3 → I3).

**하나 남은 단서 (탐색, 기술값)**
6. I3 에서 **routing 을 끈 embedding 그래프 모델 (B)** 만 FC logistic 을 넘었다 (+0.047 [+0.008, +0.085]). 그 안에서 정렬 bank 의 고유 기여는 점추정 0.014–0.036, spin · rewire 대비로는 0 에 닿는다. 결과를 본 뒤의 관찰이고 한 자료 · 한 target 이다.

## 4. 권고

**D (C + 단서 하나를 PIOP2 로 확증)** 를 권한다.

- 주가설 트랙은 세 번의 시도로 충분히 물었다 — 더 파면 사후 탐색만 늘어난다. 그래서 정리 (C) 가 중심이다.
- 다만 정리 전에 남은 단서 하나는 **사전 등록한 한 번의 확증**으로 닫는 것이 값싸고 깨끗하다. PIOP2 는 같은 과제 (emomatching) 를 가진 아직 쓰지 않은 189 명이며, 원래 이 용도로 남겨 둔 자료다.
- 확증 주장 후보 (잠금 전에 다시 물음): ① routing 고정 embedding 모델 > FC logistic, ② 그 안에서 정렬 bank > spin null. 판정 규칙 · δ · seed · 학습 규칙은 I3 잠금을 그대로 쓰고 PIOP1 결과는 보지 않은 것처럼 고정한다.
- 결과가 어느 쪽이든 종합 보고서 (결정 76) 의 마지막 장이 된다.

A 는 D 의 확증이 양성일 때 다음 단계로 둔다. B 는 지금 근거로는 권하지 않는다.
