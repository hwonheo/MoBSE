## 3. 설계 (초안 — 굵은 글씨는 §6 에서 정할 것)

| 축 | 값 | 근거 |
|---|---|---|
| 학습 · 평가 | **(가) PIOP1 157 명으로 학습 → PIOP2 189 명 평가** 또는 (나) PIOP2 안 5-fold | §6-1 |
| 입력 · 블록 | I3 와 같음 — lag 6 s · 30 s 블록 15 frame · 블록 안 ROI z-score · 8 블록 | 결정 69 |

| 첫 짝 | **전체 8 블록이 주 판정 · 첫 짝 제외가 민감도** 또는 둘 다 요구 | §6-4 |

(가) 일 때: 학습 = PIOP1 157 명 중 val 31 명 (seed 고정 무작위) 을 뺀 126 명, bank · S 도 같은 학습 피험자. PIOP2 는 평가에만 쓰고 rest 창은 쓰지 않는다 (B · D 는 gate 입력 PCA 를 쓰지 않음). PIOP2 에 필요한 것은 emomatching 블록 추출뿐이다.

## 4. 위험 · 미리 적는 한계

1. PIOP2 를 한 번 쓰면 다시 hold-out 으로 쓸 수 없다. 같은 연구 환경 (같은 장비 · 프로토콜) 이라 cross-site 라고 부르지 않는다.
2. 조건과 시간 위치가 겹친다 — P1 이 "조건" 이 아니라 "시간 위치" 를 더 잘 잡는 모델일 가능성을 배제하지 못한다.
3. P2 (spin 대비) 는 I3 크기가 참이어도 검정력 0.54 다 — 음성이어도 "기여 없음" 이 아니라 "확증 못 함" 으로 적는다.
4. I3 단서는 결과를 보고 고른 것이라 실제 효과는 더 작을 가능성이 크다.
5. (가) 는 학습 자료 (PIOP1) 와 평가 자료 (PIOP2) 의 추출 · 전처리가 같아야 한다 — PIOP2 블록 추출을 I3 재추출 코드 그대로 h197 에서 한다.

## 5. 다음 단계 (승인 뒤)

## 6. 정할 것

1. 학습 · 평가: (가) PIOP1 → PIOP2 / (나) PIOP2 안 5-fold
2. P2 의 null: spin (엄격, 검정력 0.54) / 순열 (I3 주 null, 0.92) / 순열 주 + spin · rewire 민감도
3. 판정: 하한 > 0 (97.5 %) / 하한 > δ 0.02
4. 첫 짝: 전체 주 + 제외 민감도 / 둘 다 하한 > 0 요구
5. 실행 호스트: h197 / Mac
