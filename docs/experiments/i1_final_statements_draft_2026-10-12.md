## 1. 문장 초안

각 항목의 **안 A** 가 권고안이다. 고르지 않은 안은 기록에서 지운다.

### C1 — 등변 구성에서는 정렬 그래프 대 ROI 재배열 null 이 원리적으로 같은 모델이다

- 근거: 정리 `C(x) = A(Pᵀx)` (v1 수치 1.2e−7) · MoBSE mean (AOMIC, 유일한 등변 대조) · 결정 52 문장 · 위 D1 (ABIDE 에 등변 공개 모델 없음, 결정 47).
- **안 A (권고)**: "C1 은 정리로 성립하고, 실측 대조는 MoBSE mean (AOMIC) 하나뿐이다. 그 대조에서 Δ 의 부호는 지표 · 집계에 따라 달라진다 —
  v1 방식 (seed 앙상블 · BA 0.5) 으로는 Δ −0.016 또는 0 (CI 0 포함, null seed 다섯), I1 방식 (seed 별 AUC 15 짝) 으로는 +0.0151
  [+0.0038, +0.0264]. 따라서 '실측으로 같음을 확인했다' 고 쓰지 않는다. ABIDE 에는 등변 공개 모델이 없어 (D1 학습판 최대 차 0.45–0.997)
  C1 의 실측 범위는 AOMIC 의 한 모델이다."
- 안 B: "C1 은 정리로만 진술한다. MoBSE mean 의 실측은 지표 의존 사례로 한계 절에 둔다." (본문에서 실측을 빼는 안)

### C2 — "ROI 대응을 쓰는가" 의 판정은 null 종류에 따라 달라진다

- 근거: 결정 51-2 (AOMIC) · 54-2 (ABIDE) 문장, MoBSE embedding 세 null (§11.5).
- **안 A (권고)**: "C2 는 이번 자료에서 지지되지 않았다 — 판정은 null 종류에 따라 바뀌지 않았다. 공개 모델은 두 자료 · 세 모델 모두
  n1 · n2 · n3 에서 재학습 포함 CI 가 0 을 넘고, MoBSE embedding (AOMIC) 은 순열 · spin · rewire 모두 0 을 포함한다.
  바뀐 것은 Δ 의 크기다 (n3 이 가장 작다: AOMIC 0.04–0.06 · ABIDE 0.13–0.18, n1 · n2 는 0.20–0.45). n3 은 FC–시계열 불일치가 있다 (잠금 §9)."
- 안 B: "C2 는 판정 수준에서는 지지되지 않았고, 크기 수준에서는 지지된다 — n1 · n2 의 Δ 가 n3 의 Δ 의 AOMIC 6.1–8.2 배 · ABIDE 1.3–1.7 배다."
  [계산: §11.5 · §11.10 의 Δ 평균, 모델마다 n1 · n2 각각 ÷ n3]

### C3 — 단일 학습 CI 는 재학습 변동을 빠뜨려 효과가 없어도 '유의' 를 자주 낸다

- 근거: D3 표 (§11.5 · §11.10), 결정 51-3 · 54-2.
- **안 A (권고)**: "C3 는 효과가 작은 곳에서만 관찰됐다. 효과가 큰 곳 (공개 모델 n1–n3) 에서는 단일 CI 가 짝 15/15 모두 0 을 벗어나고
  재학습 포함 CI 와 결론이 같다. 대조 n0 (짝 3) 에서는 두 자료 · 세 모델 모두 단일 CI 가 0 을 벗어난 짝이 없다.
  효과가 작은 MoBSE embedding (AOMIC) 에서는 재학습 포함 CI 가 0 을 포함하는데 단일 CI 가 0 을 벗어난 짝이 0.07 (spin) · 0.20 (순열) · 0.40 (rewire)
  이었다 (k0/r42 의 rewire 단일 −0.025 [−0.052, −0.001] 대 재학습 포함 −0.011 [−0.022, +0.001])."
- 안 B: "C3 는 지지되지 않았다 (공개 모델에서 갈린 사례 없음). MoBSE embedding 사례는 기술로만 둔다."

### C4 — 포화된 target 에서는 구조 비교가 정보를 잃는다 — 단순 FC 기준선이 그 자리를 미리 보여 준다

- 근거: 결정 51-1 (AOMIC 포화) · 54-3 (ABIDE 비포화).
- **안 A (권고)**: "AOMIC 에서는 기준선 (FC logistic 1.000 · FC-MLP 0.9999 · S1 0.9925) 과 공개 모델 원판 (세 모델 1.000) 이 모두 천장이라
  원판 성능으로는 모델 · 구조를 가를 수 없었다 — 기준선이 이를 미리 보여 줬다. 그러나 null Δ 의 판정은 포화 (AOMIC) · 비포화 (ABIDE)
  자료에서 같았다 — 포화가 null 판정을 바꾸지는 않았다. ABIDE 에서 공개 모델 원판 (0.703–0.752) 은 점추정으로 FC logistic (0.762) 보다
  낮거나 비슷하다 (CI 비교 없음 — 우열 주장 없음)."
- 안 B: 안 A 에서 "null Δ 판정은 같았다" 문장을 빼고 포화 확인만 적는다.
