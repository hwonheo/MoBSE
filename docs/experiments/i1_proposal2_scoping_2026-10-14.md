## 1. 질문

- I1 보고서 2 장 제안 2: MoBSE 는 "입력은 그대로, 모델 안의 영역 정보 (prior) 만" 뒤섞었고 공개 모델은 입력을 뒤섞었다. 공개 모델에도 MoBSE 와 같은 종류의 개입을 둘 수 있는가.
- 먼저 정할 것: 공개 모델 안에 **입력과 별개로 영역 번호에 묶인 성분**이 있는가, 있다면 그것을 섞는 것이 재학습 아래에서 의미가 있는가.

## 2. 분류 기준

| 분류 | 뜻 | 섞기가 의미 있나 |
|---|---|---|
| (a) | 학습하지 않는 고정 prior 가 영역 축을 가짐 (MoBSE 의 rest 기반 bank) | **있음** — 재학습이 정렬을 다시 맞추지 못함 |
| (b) | 영역 축을 가진 성분이 모두 학습 가중치이고 초기값이 i.i.d. | **없음** — 모든 사람에게 같은 순서로 섞고 다시 학습하면 n0 (같은 입력 순열) 과 수학적으로 같음 |
| (c) | 영역 축을 가진 내부 성분이 없음 | 입력 섞기가 유일한 개입 |

## 4. 결론

- **세 모델 모두 제안 2 를 별도 실험으로 정의할 수 없음 (0/3).**
  - 영역 축에 묶인 성분이 전부 학습 가중치라, "내부만 섞고 다시 학습" 은 n0 과 같음. n0 은 이미 돌렸고 세 모델 모두 Δ 의 CI 가 0 을 포함함 (보고서 3 장).
  - 섞을 수 있는 유일한 고정물 (BQN · BNT 의 군집 중심) 은 영역 축이 아님 — 섞어도 seed 를 바꾼 것과 분포가 같음.
- MoBSE 와 공개 모델의 차이는 **개입 방식이 아니라 구조**임 — MoBSE 에는 학습하지 않는 외부 prior 가 있고 공개 모델에는 없음.
- Han 의 순서 의존은 끝의 두 펼침 Linear 에서만 생김 (CNN · GAT 은 순열 등변, 연결은 입력에서 옴). BQN · BNT 는 FC 행을 노드 특징으로 쓰므로 첫 층부터 순서에 의존함.
