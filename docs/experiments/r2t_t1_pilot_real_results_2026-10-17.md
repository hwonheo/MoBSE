## 3. 읽기 (탐색 기술값)

- **주지표: F4R1 이 강화 기준선 BEST-T 보다 조금 나쁘다** (Δ 상한 < 0). 차이 크기는 NMSE 0.001 (보고용 δ 0.01 의 약 1/10).
- 사전에 정한 플래그: 성공 fold 모두 τ̂ = 0 → **"적응 경로 중단 권고"**. F4R1 은 모든 fold 에서 관측으로 정하는 상태 가중치를 쓰지 않는 쪽 (π 고정 비적응 혼합) 을 골랐고, 같은 성분의 pooled 판 (MIX-p) 과 차이가 없다 → **이 pilot 에서 상태별 적응의 이득 근거는 없다.**
- **정정 · 공개 (판정 플래그와 주지표의 불일치)**: 설계 §3 은 "Δ 상한 < 0 → K>1 경로 중단 권고" 를 적었는데, 고정 F4R1 코드의 플래그는 원래 BEST (7) 대비 Δ 로 계산된다 (그 Δ 상한은 +0.00043 이라 플래그가 서지 않았다). **주지표 (BEST-T 대비) 로 보면 상한 < 0 이므로 이 규칙은 "K>1 경로 중단 권고" 에 해당한다.** 코드 · 결과는 바꾸지 않고 이 차이를 여기 적는다.
- 합성과의 차이: 합성 positive 세계에서는 τ > 0 이 선택되고 이득이 컸지만, 실제 자료에서는 τ = 0 · 이득 없음. 합성 null 세계와 비슷한 양상이다. 다만 이것이 "실제 BOLD 에 상태가 없다" 는 뜻은 아니다 — 31 명 규모 · 15 frame 창 · rest 2 s 보간 · full-run 전처리 · 공간 섞임 등에서 이 방법이 상태를 잡지 못했다는 관측이다 (합성 경계: 낮은 분리도는 31 명에서 잡기 어려움).
- EM shrinkage 큰 후보 (0.5 · 0.909) 가 모든 fold 에서 점유율 실패로 빠졌다 — 실제 자료에서는 강한 shrinkage 공분산이 성분을 하나로 모으는 경향 (기술값).
