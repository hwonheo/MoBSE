## 5. 합성 이득이 한정되는 가정

- 상태는 공분산으로만 구별된다 (평균 0). 성분 공분산은 무작위 4-factor 구조이고, 상태 수 · 빈도 · 지속이 단순하다.
- 기존 세계는 상태가 15 frame 창과 정렬돼 있다 (어긋남은 새 세계에서만 따로 시험).
- 잡음은 AR(1) · 창마다 선형 drift · 사람 이득만 있다. 실제 생리 잡음 · 머리 움직임 · 전처리 섞임 (Lanczos 보간 등) 은 없다.
- rest 와 task 가 같은 상태 공분산 묶음을 공유한다 (잘못된 bank 대조는 완전히 다른 묶음뿐, 부분 공유는 시험 안 함).
- 이득 크기는 세계가 정한 상태 이득 상한에 묶여 있다 (oracle 상한 0.02–0.09).
- G-A 하한 > 0 은 null · 잘못된 bank 에서도 자주 나온다 (최대 +0.0016). **G-A 하한 > 0 만으로 상태 이득을 주장할 수 없다.** τ > 0 선택 · MIX-a 대 MIX-p 와 함께 읽어야 한다.

## 6. F1–F4 선택 과정의 탐색적 성격

- 각 수정은 앞 단계의 검증 또는 개발 결과를 본 뒤 개발 seed 진단으로 정했다:
  - F2 는 F1 검증 · 경계를 본 뒤.
  - F3 는 F2 경계를 본 뒤.
  - F4 는 F3 개발 실패를 본 뒤 (F3 검증 결과를 보기 전에 사전 기록).
- 검증 seed 는 단계마다 새로 정해 개봉 전에 기록했다. 하지만 **방법의 계열 · 후보 격자 · 합성 세계 자체를 같은 사람이 설계**했다.
- F4 의 주성분 20 은 prototype 한 값이다 (격자 탐색 없음).
- 따라서 F4 의 통과는 "이 합성 세계 계열에서 사전 지정 검증을 통과한 탐색적 결과" 다. 방법의 일반 타당성 증거가 아니다.
- 단계마다 판정 대상 묶음과 조건이 늘었다: F1 3 → F2 6 → F3 8 → F4 10. 네 단계 결과를 함께 보는 다중성은 보정하지 않았다.

1. 설계 변경 승인: pilot 설계 v1 · 계획서 v1.3 에 F4 규칙 (후보 격자 · 초기화 · 실패 규칙) 을 반영할지. 반영하면 새 판 문서와 새 잠금이 필요하다.
2. 실패 규칙 선택: 기존 중단 규칙 vs F4 fallback. fallback 이면 실패율 · fallback 사용률 보고와 높은 실패율의 해석 기준을 미리 정한다.
3. **수치 오류 처리 보완 (4 절 e)**: 비 SPD · numerical 실패를 중단으로 둘지 fallback 으로 둘지 정하고 구현과 문서를 맞춘다. 재시작 · 후보 단위 실패 원인 (status · reason · fold · a) 을 결과에 저장한다.
4. 결과 저장 범위: 사람별 · fold 별 NMSE 와 선택 기록 (inner 명단 · 후보 점수) 을 저장해 사후 감사가 가능하게 한다.
5. BEST 후보: 7 후보를 유지할지, 후보 수 비대칭 (240 대 7) 을 줄일지 (예: BEST 쪽 후보 확장 또는 MIX 격자 축소). 결정 사항.
6. 해석 기준: G-A 하한 > 0 이 null 에서도 나오므로, τ > 0 · MIX-a 대 MIX-p 등 기전 조건을 함께 둘지.
