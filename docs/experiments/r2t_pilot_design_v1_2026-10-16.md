| 자료 (PIOP1 기존 산출만) | task: I3 `full_ts` emomatching (run 단위 회귀 · ROI z-score, TR 2 s, 135 frame). rest (train 전용): `derivatives_v3` rest 창 4 × 30 frame (2 s 격자) → 15 frame 창 8 개/사람 | 재추출 · 다운로드 없음. manifest [측정]: 157 run 모두 ok · 135 frame · QC 통과 |
| 대상 · 선정 규칙 | `folds.json` 의 **pilot 31 명** (WI-03 적격 규칙 = 세 task 모두 · QC, pilot seed 20260917, 1 사람 = 1 group). 추가 제외 없음 | 고정 목록이라 결과를 보고 고를 수 없음. 이 31 명은 다른 가설 (v1 · I3) 의 pilot 에 쓰인 적 있음 — R2T 결과는 본 적 없음 |
| 분리 | 사람 단위 5 fold (seed **20261017**), test 6–7 명 · train 24–25 명. fold 안 inner train 80 % · inner val 20 % (seed **20261018**). 같은 사람의 창은 한쪽에만 | 31 명이라 inner val 은 약 5 명 — 선택이 불안정할 수 있음 (보고) |
| 창 · mask | 겹치지 않는 15 frame 창, frame 0 부터 → 9 창/사람. mask: 20 % (반구별 10), **M = 10 벌** (seed **20261019**), 모든 사람 · 창 · 방법 공통 | 15 frame = PIOP 블록 30 s 길이 · I3 와 같은 단위. 20 % = 가린 20 · 관측 80 의 절충. **둘 다 문헌 기준 아님**. 창이 블록 경계를 걸칠 수 있다 (T1 복원에는 무관, 상태 해석에는 한계) |
| 모델 · 선택 (train 측만) | BEST 후보: G1-LW · G1-OAS · RIDGE λ ∈ {100, 10, 1, 0.1, 0.01}. MIX: **K = 3 고정**, τ ∈ {0, τ_ESS, 1}. 둘 다 inner val NMSE (분모 inner train) 로 선택, 동률 (< 1e-4) 이면 단순한 쪽 (G1 · 큰 λ · 작은 τ). 선택 뒤 fold train 전체로 재적합 | pilot 은 최소 범위 — RRR · LAG-RIDGE · K 선택은 본 분석에서. 그래서 pilot 의 BEST 는 본 분석보다 약할 수 있다 (낙관 쪽 치우침, 보고) |
| 공분산 · EM 규칙 | 평균 0 고정 (run z-score), 창 단위 EM, 책임도 가중 Ledoit-Wolf + 고유값 하한 1e-6 × 평균 고유값, k-means++ 초기화 10 회 (seed 1–10), 수렴 1e-6 · 500 회, 최소 점유율 5 % | 합성 검증 (handoff §11.52–§11.54). LW 강도 공식 · τ_ESS 는 frame 독립 · 짧은 창 때문에 치우침 (합성: τ_ESS 과대) |
| 실패 처리 | 혼합 적합 실패 fold 는 "실패" 로 기록, G1 대체 없음. τ̂ = 0 fold 는 "적응 미선택" | 계획 §4.4 |
| 주지표 | 사람별 NMSE (가린 ROI 정답 = 기존 z-score 값, 분모 v_r = 그 fold train 의 task 창 분산). Δ = NMSE(BEST) − NMSE(MIX-a), 양수 = MIX-a 가 나음. 31 명 (fold 합침) 피험자 bootstrap 10,000 (seed **20261020**) 95 % | 창 · frame 을 독립 표본으로 세지 않음. bootstrap 은 선택 변동을 포함하지 않음 |
| δ | **NMSE 0.01** (train 분산의 1 %) 은 본 분석용 제안값. **pilot 은 δ 로 성공을 판정하지 않는다** — 점추정 · CI 와 Δ 의 사람 간 SD 를 보고해 본 분석 (126 명) 검정력 계산에 쓴다 | 문헌 기준 없음. 합성 이득 (+0.035 ~ +0.087) 은 실제로 옮길 수 없음 |
| 보조 (판정 무관) | MIX-p · MIX-f 대조, 경계 완충 민감도 (가린 ROI 와 atlas 상 맞닿은 관측 ROI 제외), fold 별 선택값 · inner 곡선, τ_ESS · 조건수 · shrinkage | 기전 대조는 단독 근거로 쓰지 않음 (합성 잘못된 bank 예) |
| 중단 기준 | ① 아래 정보 범위 확인 실패 → 실행 안 함. ② 혼합 실패 fold ≥ 2/5 또는 비유한 예측 · 비 SPD → 중단 · 보고. ③ Δ 상한 < 0 (분명한 손해) → K>1 경로 중단 권고. ④ 모든 fold τ̂ = 0 → 적응 경로 중단 권고. 그 밖 → 기술값 보고 뒤 본 분석 잠금 여부를 묻는다 | pilot 결과로 본 분석 기준을 바꾸면 새 탐색 판 (계획 §5) |
| 정보 범위 확인 조건 (값을 읽기 전) | 추출 코드 판본 sha 기록 · 회귀 / z-score 가 ROI 별 · 설계에 global_signal · tCompCor 없음 (코드), manifest 157 ok · 135 frame, pilot 31 명의 rest 창 4 개 · full_ts 존재 (파일 목록만), 적합 함수가 test 사람 자료를 받지 않음 (시험) | fMRIPrep 보고서 · 설정은 로컬에 없어 **미확인** — 한계로 기록 |
| 계산량 [추정] | CPU 만, fold 당 20–40 s, 전체 5 분 이내, 최대 RSS 1 GB 미만. GPU 불필요 | 근거 [측정, 합성]: 100 ROI · train 100 명 혼합 적합 12.5 s, ridge 13 λ × 20 mask 5.5 s, RSS 476 MB. 산출물은 로컬 별도 경로에 보존, 기존 결과 덮어쓰기 없음 |
